# Glossary

| Term | Meaning |
|---|---|
| **Tier** | Risk level 0–4 for a message (see [[Safety and Crisis Flow]]) |
| **Lexicon** | List of risk phrases matched against messages |
| **LLM risk judge** | Claude classifying a message's risk; can only raise the tier |
| **Floor** | Minimum tier applied to a user for a while after earlier risk |
| **Crisis template** | Fixed, clinician-approved crisis reply |
| **Output guard** | Checks on AI replies (diagnosis, dosage, "I'm human", links, numbers) |
| **Escalation / handoff** | Request to connect the user to a human counsellor |
| **SLA** | Target time to connect a counsellor (5 minutes) |
| **Check-in** | Follow-up message after elevated risk |
| **DEK** | Per-user data encryption key |
| **Master key** | Key that encrypts every user's DEK |
| **Redaction** | Replacing personal details with placeholders before text leaves Koyala |
| **PHQ-9 / GAD-7 / WHO-5** | Standard depression / anxiety / wellbeing questionnaires |
| **Safety plan** | User's personal plan (Stanley–Brown model) for when things get hard |
| **Tele-MANAS** | Government of India mental-health helpline, 14416 |
| **DPDP** | India's Digital Personal Data Protection Act, 2023 |
